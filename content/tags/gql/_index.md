Geode documentation tagged with **gql**. GQL (Graph Query Language) is the ISO/IEC 39075:2024 standard for querying property graph databases.

## What You'll Find

Content with this tag covers:

- Pattern matching with MATCH clauses
- Data manipulation (INSERT, SET, REMOVE, DELETE)
- Advanced path patterns and variable-length relationships
- 100% ISO compliance with all 70 test cases passing

## Relevance to Geode Database

Geode's GQL implementation is fully standards-compliant, making it one of the first production-ready databases to support the complete ISO specification.
