The **Query Language & Optimization** category provides comprehensive documentation for Geode's ISO/IEC 39075:2024 GQL implementation. From basic pattern matching through advanced optimization techniques, these resources cover the complete query language including syntax, semantics, and best practices.

## Introduction

GQL (Graph Query Language) is the ISO standard for querying property graphs, providing declarative syntax for expressing complex graph patterns. Geode implements 100% of the ISO/IEC 39075:2024 specification, offering pattern matching, CRUD operations, aggregations, subqueries, and path queries. The declarative nature means you specify what data you want, not how to retrieve it—the query optimizer determines the execution strategy.

This category documents GQL comprehensively: basic MATCH patterns for graph traversal; WHERE clauses for filtering; RETURN for projection; INSERT, SET, and DELETE for data manipulation; aggregations for analytics; subqueries for complex logic; and optimization techniques for performance. Whether learning GQL for the first time or mastering advanced optimization, these resources provide the knowledge you need.
