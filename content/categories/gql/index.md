The **GQL** category provides comprehensive documentation on the Graph Query Language, the ISO/IEC 39075:2024 standard for querying property graphs. GQL is the ISO standard for querying property graphs, and Geode is 100% compliant.

## What You'll Find

GQL documentation includes:

- Language guide from basics to advanced patterns
- Pattern matching and graph traversals
- Data manipulation operations
- ISO conformance and standards compliance

## Relevance to Geode Database

Geode passes all 70 ISO GQL test cases, ensuring standards compliance and application portability.
